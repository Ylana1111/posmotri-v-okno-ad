 Проект "Посмотри в окно"

Учебный проект по вёрстке в рамках курса веб-разработчик Яндекс.Практикум.

 Функциональность:
- Адаптивная и валидная вёрстка по макету Figma.
- Кастомные элементы форм (чекбоксы, инпуты).
- Состояния интерактивных элементов (hover, active, focus-visible).
- Работа с шаблонами (template) и встроенными прелоадерами.

Технологии:
- HTML5
- CSS3 (Flexbox, Grid, анимации)
